# sportmatch
⚽🏀 SportMatch

Aplicativo Flutter para encontrar pessoas que praticam os mesmos esportes e organizar partidas e eventos.

📱 Funcionalidades

Tela de boas-vindas (Onboarding).

Navegação entre Explorar, Eventos e Perfil.

Lista de esportes para explorar.

Lista de eventos esportivos com detalhes e confirmação de presença.

Tela de perfil com:

Cadastro de nome, idade, esporte favorito e nível.

Upload de foto de perfil (câmera/galeria).

Armazenamento local com shared_preferences.
